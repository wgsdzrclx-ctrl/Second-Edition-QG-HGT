**步骤2：实现固定标准化和图输入传递。**

- 新增`data/standardization.py`：仅允许训练分区拟合，读取选定窗口覆盖的原始有效观测，按run/时间点去重；float64合并均值和方差；零有效观测拒绝拟合；常量变量使用epsilon下限。提供可序列化尺度、选窗指纹和选定观测内容指纹。
- 修改`data/tep_hetero_graph.py`：标准化在原单位退化后进行；主输入统计量和移位负例统计量使用同一尺度；质量分支继续保留原始单位窗口。新增互不冲突的0–51变量ID、0–5单元ID，以及正/负时序窗口与mask；功能关闭时保留旧路径。
- 修改`models/common.py`：统一接口完整传递sensor/actuator时序、身份、负例和尺度指纹，不再丢失执行器时序或物理身份。
- 只完成代码编辑，尚未执行拟合、模型前向或测试。

**步骤3：实现C/D组身份与时序编码。**

- 新增`models/input_representation.py`：共享两层因果TCN，默认32维、kernel=3、dilation=1/2；输入为标准化值、mask、有效相邻差分，按有效时刻池化整个窗口；全缺失时输出零。
- 修改`models/qc_hgt.py`：新增默认关闭的`representation`开关；C组拼接16维变量身份及8维单元身份，D组再拼接32维时序向量，统一投影到原64维。单元时序向量按原工艺边聚合，原池化与图传播结构保留。
- 正样本与时移负例通过同一编码器，负例使用自身移位窗口及mask。质量描述仍取原单位观测；原损失及负采样策略保持不变。
- 模型核对图输入的尺度指纹，拒绝增强模型缺少尺度、尺度错配或旧模型静默读取标准化输入。
- A组不开新模块，不增加embedding/TCN参数或其初始化随机数消耗；实际数值兼容性尚待用户允许后测试。

**步骤4：增加实验追溯与训练记录。**
